# [Aurora DSQL adapter for Drizzle ORM v0.1.0 (node/drizzle/v0.1.0)](https://github.com/awslabs/aurora-dsql-orms/releases/tag/node/drizzle/v0.1.0) - 2026-08-25

Initial release of the Aurora DSQL adapter for Drizzle ORM

- `drizzle()` factory building an IAM-authenticated `AuroraDSQLPool` over `drizzle-orm/node-postgres`
- `db.transactionWithRetry()` — opt-in transactions with retry on DSQL optimistic-concurrency conflicts (`OC000` / `OC001` / `40001`)
- `migrate()` — resumable migrations applying one DDL per transaction, waiting on asynchronous DDL jobs before recording completion
- `aurora-dsql-drizzle` CLI: `generate` / `transform` / `lint`, rewriting migrations for DSQL via dsql-lint
- Veterinary app example demonstrating the full workflow on a live cluster

See README for full documentation.
